# OpenTailcat 1.4.0

Adds a speed-test troubleshooter clipboard report and Settings in-app update
check/install. No data-plane capability promotions; no native/AAR changes.

## Features

- **Troubleshooter report**: after a Network Benchmark completes or fails, the
  top bar can copy a plain-text report (stage, metrics, tunnel state, findings)
  suitable for a GitHub issue. Public IPs in free-form diagnostic text are
  redacted. Backed by `SpeedTestState.metricsSnapshot` / `tunnelState` and
  `SpeedTestReport`.
- **Settings → Updates**: checks `api.github.com/.../releases/latest`, picks
  the ABI-matching APK asset, downloads into app cache, verifies SHA-256 when
  the release provides a digest, signature-compares the archive against the
  installed app, then installs via FileProvider + `REQUEST_INSTALL_PACKAGES`.
  Signature-mismatch and download failures surface as explicit error states;
  "Open release page" remains available as a fallback.

## No data-plane capability promotions

- IPv4 test-routing flags unchanged; Phase 8 physical leak acceptance still
  pending (`testRouting: true`). This release is **not** a leak-free or
  production VPN claim.
- Unchanged AAR SHA-256:
  `986c21150a4da2890b78023523a9b2bd6415ddc68de301000e792af6c16a2436`
  (sourcehash `1916945b42a9ae78ffa2ad070752c1d60063f1276eaa5d968e2fb8af2764a075`).
- Development-signed unless `OPENTAILCAT_RELEASE_*` is set.

  (separate invocations so ABI splits stay enabled)
