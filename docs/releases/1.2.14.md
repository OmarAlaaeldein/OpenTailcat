# OpenTailcat 1.2.14

Development build. Not a production privacy VPN. Do not claim leak-free.

## Highlights

- **Fix status notification / TelemetryCard showing `0 B/s` (or `0 B`) while the
  tunnel carries traffic.** Schema v2 keeps `txBytes`/`rxBytes` as WireGuard peer
  counters only; upstream `Client` has no Status API, so those fields stay 0.
  The notification was rendering those WG zeros as the live speed line.
- Foreground notification now shows **live upload/download rates** from
  `txRateKbps`/`rxRateKbps` (TUN pump accounting via `rateCalcLoop`).
- TelemetryCard cumulative totals now use `tunTxBytes`/`tunRxBytes` instead of
  the always-zero WG aliases. Rates were already sourced from `*RateKbps`.
- Shared `TrafficFormat` helper + unit coverage; Go test that `rateCalcLoop`
  derives non-zero rates from TUN counters without falling back into `txBytes`.

## Not claimed

Phase 8 physical dual-capture / leak-free / production signing. Always-on
lockdown still required on Android 10+. Development-keystore signing when
`OPENTAILCAT_RELEASE_*` is unset. Native AAR unchanged from 1.2.13 (Kotlin UI
fix only).
