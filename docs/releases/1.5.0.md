# OpenTailcat 1.5.0

Fixes from the 2026-09-26 code and security review (P0–P3), Tailcat v0.7.0,
and a speed test that shows its progress through the gateway. Development
build: signed with the same development certificate as 1.4.0, so it installs
over it and the in-app updater accepts it. Phase 8 physical leak acceptance
is still pending (`testRouting: true`). This is **not** a production, secure
or leak-free VPN release.

## Fixes you will notice

- **Speed test through the gateway**: the gauge now moves during the download
  and upload instead of sitting at 0 until the end.
- **Reconnects instead of silently stopping**: a mid-session engine failure or
  a gateway that stops answering for 60 s closes the tunnel at once and the
  service retries with backoff; the notification says RECONNECTING and why.
  Always-on starts no longer give up when the network is not yet validated.
- **Network changes** (Wi-Fi ↔ mobile data) now reach the tunnel's transport,
  so it rebinds instead of waiting up to 10 minutes.
- **Honest status**: a gateway that stops answering shows "GATEWAY NOT
  RESPONDING" instead of a stale transport and RTT; IPv4 ping is no longer
  answered locally (it used to report every host as reachable).
- **Switching gateways** stops the running session; the token dialog is
  hidden from screenshots; deleting a gateway asks first and stays deleted.
- **Lock screen**: the notification's Disconnect action requires unlocking.
- **Settings > Updates** verifies the APK's SHA-256 against GitHub's digest,
  only downloads from GitHub, and checks the signing certificate before
  offering to install.
- **Licenses**: Settings > About lists every bundled library and its license.

## Data plane

- TCP half-close is passed through (replies after the client finishes sending
  are no longer cut off); local TCP buffers are bounded (128 KiB / 1 MiB).
- UDP: one device-wide flow table of 1024 flows with least-recently-used
  eviction; payloads over 1232 B get ICMP Fragmentation Needed / Packet Too Big
  instead of vanishing in the tunnel; an IPv6 DNS server on a gateway without
  IPv6 no longer blacks out DNS.
- `tcpOnly` is decided by STUN through the tunnel (a gateway that answers only
  DNS no longer counts as UDP-capable) and re-latched when UDP stops working;
  DNS over TCP reuses one pipelined connection per app socket.
- Logcat no longer carries the public IP, local addresses or peer endpoints
  unless Settings > Diagnostics is on.
- Counters: plain DNS queries forwarded, plus link-queue and UDP-buffer drops.
- Native `Stop` returns within about 3 s; every exported native call recovers
  a panic instead of crashing the app.

## Storage

- Saved gateways move from the deprecated `EncryptedSharedPreferences` to
  values sealed with an AES-256-GCM Android Keystore key, migrated once on the
  first start. If the Keystore key is ever lost, the app starts with no saved
  gateways instead of crashing at every start.
- One corrupt saved gateway no longer drops all of them.

## Engine and build

- Tailcat submodule: the signed `v0.7.0` tag (was an unsigned `main` commit),
  which brings upstream wireguard-go and gVisor performance changes.
- Go Mobile Java package `com.tailcat.golib.engine`: R8 now optimizes the app's
  own code (the old package name kept the whole app from shrinking).
- Compose BOM 2026.09.00 (compileSdk 37; targetSdk stays 35).
- CI: gofmt, staticcheck, govulncheck, an emulator smoke test, and a nightly
  live-gateway emulator run.

## Verification

- `go test -race ./...`, `go vet ./...`, staticcheck, govulncheck (no
  vulnerabilities affecting the code), Phase 8 analyzer e2e.
- `./gradlew testDebugUnitTest lintDebug` (140 unit tests),
  `assembleDevelopment`, `bundleDevelopment`.
- API 35 emulator with a live gateway: startup smoke test, Keystore storage
  migration from 1.4.0 data, log privacy, tunnel UDP payload limit, TCP
  half-close, DNS burst, Wi-Fi/cellular roaming, gateway loss and reconnect,
  lock-screen Disconnect, gateway speed test.
- Not done: Phase 8 physical-device packet capture.
