# OpenTailcat 1.6.5

## Changes

- **New look.** A shared design system across Home, Speed Test and Settings:
  glass-style panels, a redrawn connect ring and speed gauge, tabular numerals
  for live values, and a fade between screens. The title no longer overlaps the
  status bar, system-bar icons stay light, and all text meets WCAG AA contrast.
  Animations are skipped when the system has them turned off, and the app stops
  collecting state while it is in the background.
- **Correct upload/download counters.** The totals are the bytes that cross the
  VPN interface in each direction, headers included, which is the same number
  the kernel keeps for the interface. Before, locally generated ICMP errors were
  counted in one direction and not the other. Rates are rounded instead of
  floored.
- **Consistent units.** Totals use kB, MB and GB and rates use kb/s, Mb/s and
  Gb/s, all decimal, so 100 Mb/s for 10 seconds reads exactly 125.0 MB (it used
  to read 119.2 MB). A value just below a boundary rolls over instead of
  printing "1024.0 KB". The notification uses the same rate format.
- **QR import from an image.** Pairing no longer launches an external scanner
  app. Choose an image; it is decoded on the device, with size limits, and no
  camera permission is requested.
- **Transport sockets protected at creation.** Tailcat transport sockets are
  protected with `VpnService.protect` when they are created, through a small
  OpenTailcat-maintained integration of the pinned upstream. The process-wide
  sweep of open sockets is gone, and a missing protector now fails the socket
  instead of passing silently. The network monitor uses a typed API instead of
  reflection.

## Verification

Go: tests, race detector, vet, staticcheck and govulncheck. Android: 162 unit
tests per flavor, lint for both flavors, and the optimized APKs. On an API 35
emulator: the QR import, VPN startup, storage and start-id instrumented tests,
and the offline native socket-protection tests. The counter tests compare the
engine's totals with independently counted bytes, and were checked to fail
against the previous counting rule. Both APKs are signed with the pinned
development key and carry the configured updater repository.

This release was not exercised against a live gateway.
