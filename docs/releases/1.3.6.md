# OpenTailcat 1.3.6

Adds a speed-test troubleshooter that surfaces silent tunnel failures, and
tidies stale documentation from the 1.3.5 line.

## What you get

- **Speed test diagnostics**: when a benchmark fails or completes under a
  connected tunnel, the Network Benchmark screen now lists warnings such as
  stale discovery RTT, DERP relay path, TCP-only gateway, elevated tunnel RTT,
  data-plane drop counters, and dead tunnel health — instead of a single
  generic error.
- **Stage attribution**: failures name the stage that broke (ping / download /
  upload) and whether the path was gateway (`Client.DialTCP`) or physical
  (app-UID) network.
- **Private-IP text policy**: free-form diagnostic strings redact public
  endpoints (`[ip-redacted]`); private/loopback hints stay readable.

## Fixes & cleanup

- `handoff.md` / `SECURITY.md`: corrected stale AAR SHA, `ipv6: false`
  contradiction, hard-coded bridge-MTU note, and DNS policy-picker wording.
- Removed unused Espresso / Compose UI-test Gradle dependencies (kept
  `androidx.test:runner` for instrumentation).
- Native AAR rebuild (PREPARED `rttMs`, MTU bridge, liveprobe helpers);
  sourcehash sidecar now CI-gated.
- `README`/release notes updated for 1.3.6 / versionCode 36.
