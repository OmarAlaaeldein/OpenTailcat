# OpenTailcat 1.2.7

Development build. Not a production privacy VPN. `ipv6` remains false.

Built with the `development` build type: release R8/resource optimization with
the existing development certificate and no debug UI tooling. `release` signing
remains separate; never debug-key-sign a release.

1.2.7 takes versionCode 20 to keep phone installs distinct from 1.2.6
(versionCode 19). It fixes the "websites dead, speedtest green" class of
failure and wrapped-token paste errors observed against the live `nullexit`
gateway.

## What changed since 1.2.6

- Strict interior-whitespace token error: a wrapped `tc...` paste (line break
  or spaces introduced when copying) is rejected as `ERR_WHITESPACE` with a
  paste-specific message instead of a generic Base64 error. Kotlin and Go
  agree; no silent normalization. Paste the token as one line.
- UDP capability probe hardened: the one-shot 1s `SupportsUDP` latch in
  `Prepare` became a 5s bound, and the bridge re-probes every 30s while
  `tcpOnly` is latched, clearing it when gateway UDP recovers. A slow
  DERP-relayed mobile path can no longer permanently drop non-DNS UDP for the
  session while the TCP-only speedtest stays green. Re-probing only ever
  re-enables gateway-proxied `Client.DialUDP`, never direct OS sockets.
- `tcpOnly` telemetry (schema still v2, additive field): `getStatsJSON`
  reports the measured latch, Kotlin parses it into `NetworkMetrics`, and the
  home telemetry card shows a "TCP-only" badge while active.
- Version bump to 1.2.7 / versionCode 20. AAR rebuilt after the Go changes
  (Go 1.27.1 + NDK r29, 16 KB ELF alignment, verified Java signatures).
- Live evidence (host harness + API 37 emulator, nullexit gateway): gateway
  UDP DNS and TCP/TLS egress verified via `Client.DialUDP`/`DialTCP` with
  gateway-supplied DNS answers; native `prepare` handshake succeeds through
  the Android app path with `tcpOnly=false`; tunnel measurements fail closed
  without a running TUN. Full-device TUN connect on the emulator stays
  fail-closed (`LOCKDOWN_REQUIRED` on S+). `ipv6` stays false.
