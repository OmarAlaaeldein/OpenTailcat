Development test build. This is not a production privacy VPN.

The downloads have been rebuilt with code and resource shrinking: ARM64 is now
20.8 MB (previously 37.0 MB), and x86-64 is 22.2 MB (previously 38.4 MB). Build 16
installs over the original 1.2.3 build. The optimized packaging source is tagged
[`v1.2.3-optimized`](https://github.com/OmarAlaaeldein/OpenTailcat/tree/v1.2.3-optimized).

- Checks Android VPN permission before starting or restoring a connection and again inside the service.
- Handles foreground-service rejection and completes notification/service cleanup without the reproduced process crash.
- Clears the saved reconnect request after startup fails, preventing repeated automatic retries. An explicit Connect can retry after permission is granted.
- Adds an emulator regression for missing consent, queued service rejection, process survival, retry, and service/notification cleanup.
- Includes the intervening main-branch lockdown/split-exclusion guards and the `detachTun` handoff between VPN interfaces.

Validation: 49 Android unit tests, lint, and optimized APK builds passed. Lint retains 16 existing warnings. APK signatures and 16 KB alignment were verified; the native libraries are byte-identical to the original 1.2.3 APKs.

The optimized APK passed emulator checks for consent cancellation, retry,
service cleanup, and profile retention after reopening. The existing minified
instrumentation runner could not start because of removed shared dependencies;
that limitation and the direct UI results are documented in the
[verification record](https://github.com/OmarAlaaeldein/OpenTailcat/blob/v1.2.3-optimized/docs/verification/1.2.3-optimized.md).

Known limits: the lockdown startup check can still refuse a connection even when lockdown is enabled. Transport socket protection and other lifecycle issues remain unresolved. Full-device encrypted traffic, physical-device behavior, and leak acceptance have not passed; `ipv6` remains false. The reported phone crash has not been confirmed to share the emulator's cause.

The APKs use the optimized `development` build type, with debugging and debug UI tooling disabled. They are signed with the same development certificate as 1.2.2 and the original 1.2.3, with version name 1.2.3 and version code 16. Use the ARM64 APK for ARM64 phones or the x86-64 APK for x86-64 devices/emulators. SHA-256 checksums are supplied with the downloads.
