# OpenTailcat 1.5.1

Bugfix follow-up to 1.5.0 from an independent audit of the app layer and the
Go data plane. Development build: signed with the same development
certificate as 1.5.0, so it installs over it and the in-app updater accepts
it. Phase 8 physical leak acceptance is still pending (`testRouting: true`).
This is **not** a production, secure or leak-free VPN release.

## Fixes

- **Routed interface tracking** (`TailcatVpnService`): the active interface is
  now compared by object identity only. Linux reuses the lowest file
  descriptor number after `close()`, so the old fd-integer comparison could
  clear a newly established routed TUN that recycled the warm TUN's number.
- **`vpnWanted` durability** (`PreferencesStore`): stored synchronously, so a
  process killed right after Disconnect cannot resurrect an unwanted VPN (and
  vice versa).
- **Stored MTU agreement** (`ProfileRepository`): profiles loaded from JSON
  are clamped to 1280–1500, matching `PreferencesStore` and the native
  bridge clamp, so a tampered value cannot split Builder and native behavior.
- **Token IPv4 agreement** (`TokenParser`): embedded DERP IPv4 literals reject
  leading zeroes, matching Go `netip.ParseAddr` and `DnsValidator`.
- **Roam error visibility** (`TunnelEngine`): a failed `updateNetworkState`
  call is now logged instead of silently swallowed.
- **Native TCP dial** (`core-engine/netstack_proxy.go`): a panicking `DialTCP`
  now signals the waiter instead of blocking `proxyTCP` forever and leaking
  its 512-connection slot and wait-group credit; dial waits also return on
  engine shutdown.
- **Native staged MTU** (`core-engine/lifecycle.go`): `Stop` clears
  `pendingMTU` alongside `pendingDNS`, matching `abandonPrepare`.
- **AAR rebuilt** reproducibly (Go 1.27.1, NDK 29.0.14206865, 16 KB ELF load
  alignment, verified Java signatures); `.gitignore` now also covers
  `*.pcapng`, `*.cap`, `live-token.txt`, `*.key`, `*.der`, `*.p8`,
  `keystore.properties`, `signing.properties`, and `.env.*`.

## Verification

- `go test ./...`, `go test -race ./...`, `go vet ./...` (clean).
- `./gradlew testDebugUnitTest lintDebug` (clean),
  `./gradlew assembleDebug assembleDebugAndroidTest`.
- API 35 emulator smoke (`scripts/emulator/ci-smoke.sh`): PASS.
- Live gateway suite (`scripts/emulator/ci-live.sh`): BLOCKED — Connect fails
  with `gateway handshake failed: context deadline exceeded` from both the
  emulator and host liveprobe, while direct pinned-host handshakes succeed;
  the test gateway is unreachable (external outage, not a regression from
  these changes).
- Not done: Phase 8 physical-device packet capture.
