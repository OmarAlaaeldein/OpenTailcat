Development test build. This is not a production privacy VPN.

- Checks Android VPN permission before starting or restoring a connection and again inside the service.
- Handles foreground-service rejection and completes notification/service cleanup without the reproduced process crash.
- Clears the saved reconnect request after startup fails, preventing repeated automatic retries. An explicit Connect can retry after permission is granted.
- Adds an emulator regression for missing consent, queued service rejection, process survival, retry, and service/notification cleanup.
- Includes the intervening main-branch lockdown/split-exclusion guards and the `detachTun` handoff between VPN interfaces.

Validation: the startup regression passed on an API 37 ARM64 emulator with 16 KB pages; 49 Android unit tests, lint, and debug APK builds passed. Lint retains 16 existing warnings. The native AAR is unchanged from the audited main branch.

Known limits: the lockdown startup check can still refuse a connection even when lockdown is enabled. Transport socket protection and other lifecycle issues remain unresolved. Full-device encrypted traffic, physical-device behavior, and leak acceptance have not passed; `ipv6` remains false. The reported phone crash has not been confirmed to share the emulator's cause.

The APKs are debug builds signed with the same development certificate as 1.2.2, with version name 1.2.3 and version code 15. Use the ARM64 APK for ARM64 phones or the x86-64 APK for x86-64 devices/emulators. SHA-256 checksums are supplied with the downloads.
