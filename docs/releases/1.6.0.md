# OpenTailcat 1.6.0

Development preview, versionCode **49**, signed with the existing development
key. The data plane remains a test-routing preview and is not accepted for
privacy-sensitive traffic.

## Changes

- Fix connect/disconnect and reconnect races across Android service instances,
  including stale start jobs, delayed STOP intents and queued starts.
- Prevent obsolete pump callbacks and telemetry/network callbacks from changing
  a newer or stopped session.
- Align Kotlin and Go token validation, reject malformed UTF-8, and make error
  classification deterministic.
- Disable app HTTP connection reuse across tunnel transitions so an earlier
  protected connection cannot remain pooled into a later VPN session.
- Add lifecycle model checks, focused cleanup and termination checks,
  reproducible counterexample schedules, fuzz targets and shared parser
  differential fixtures.
- Add Android platform regression coverage for queued/newer-start service
  ordering and harden the formal checker against incomplete runs and crashes.
- Gate live emulator CI on real Wi-Fi/cellular roaming, background forwarding,
  and screen-off forwarding. Add credential-free health failure diagnostics
  for automatic reconnects.

## Verification

The final optimized ARM64 APK passed live-gateway forwarding with the app on
Home for two minutes and the screen off for over five minutes. All 21 traffic
probes passed with CONNECTED and the same TUN route table; after the initial
screen-off transition, all 20 later samples confirmed Android was asleep.
DNS bursts answered 20/20 queries in both phases. This is API 35 emulator
evidence, not real-device Doze acceptance.

Local checks passed: 155 unit tests per flavor (no skips), both debug lint
checks, optimized GitHub APKs, the F-Droid release APK, and the GitHub release
bundle. Both APKs have version 1.6.0 / 49, the existing pinned development
signer, and the configured updater repository; their SHA-256 hashes are below.

Publication requires all CI release gates to pass:

- [Host CI](https://github.com/OmarAlaaeldein/OpenTailcat/actions/workflows/ci.yml):
  Go race tests, vet, staticcheck, govulncheck, AAR source/hash and cross-host
  rebuild checks, Android unit tests, lint, and optimized builds.
- [Formal CI](https://github.com/OmarAlaaeldein/OpenTailcat/actions/workflows/formal.yml):
  translation, checker regressions, deterministic counterexamples, focused
  cleanup/liveness and network-callback models, and all six extended shards.
  Larger scenarios remain random samples; these models do not prove the app
  secure or mechanically verify the implementation.
- [Emulator CI](https://github.com/OmarAlaaeldein/OpenTailcat/actions/workflows/emulator.yml):
  smoke and live-gateway checks, including real Wi-Fi/cellular roaming and
  TCP forwarding every 15 seconds while backgrounded and asleep.

Physical leak capture, real-device roaming/captives/Doze, IPv6 WAN acceptance,
and production signing remain outstanding. Reconnect attempts have no TUN between them; Android
Always-on lockdown is required to block traffic during those gaps.
