# OpenTailcat 1.5.3

Security update for the native engine. Development build: signed with the same
development certificate as 1.5.2, so it installs over it and the in-app updater
accepts it. Phase 8 physical leak acceptance is still pending
(`testRouting: true`). This is **not** a production, secure or leak-free VPN
release.

## Changes

- **Go 1.27.2 and `golang.org/x/net` v0.60.0** (`core-engine/go.mod`,
  `app/libs/libtailcat.aar`): fixes GO-2026-6611, GO-2026-6612, GO-2026-6613
  and GO-2026-6617 in `net/http` and the HTTP/2 code, all reachable from the
  engine. `core-engine/build-aar.sh` now requires exactly Go 1.27.2, so the
  checked-in AAR cannot be rebuilt with the vulnerable standard library.
  `libgojni.so` reports `go1.27.2`; govulncheck reports no vulnerabilities.
- **Third-party notices**: `THIRD_PARTY_NOTICES.txt` regenerated for the new
  Go and x/net versions; `scripts/licenses/generate-notices.sh` now resolves
  the `githubReleaseRuntimeClasspath` configuration after the flavor split.
- **Emulator/CI reliability**: emulator scripts pre-grant `POST_NOTIFICATIONS`
  so the first Connect is not hidden behind the permission prompt, wait for a
  readable UI dump before deciding whether to tap Connect, and a skipped live
  gateway job is reported as a warning. CI uses flavor-explicit Gradle task
  names (`testGithubDebugUnitTest`, `lintFdroidDebug`, …) and staticcheck
  v0.8.2 for the Go 1.27.2 export-data format.

## Verification

- `./gradlew assembleFdroidRelease -PnoAbiSplits testFdroidDebugUnitTest`
- `./gradlew assembleGithubDevelopment`
- `core-engine/build-aar.sh` with Go 1.27.2 reproduces the committed
  `app/libs/libtailcat.aar.sourcehash`.

```bash
./gradlew assembleGithubDevelopment
./gradlew bundleGithubDevelopment
./gradlew assembleFdroidRelease -PnoAbiSplits   # F-Droid (unsigned)
```
