# OpenTailcat 1.3.2

Visual polish on the dark UI. Development signing when
`OPENTAILCAT_RELEASE_*` is unset.

## Highlights

- Leaner chrome: softer glow alphas, thinner power-ring stroke, tighter
  card radii/padding and home vertical spacing.
- Accents (cyan / emerald / violet) slightly refined; hierarchy calmer
  without a redesign.
- Still forced **dark** theme — no system light scheme.
- Version **1.3.2** / versionCode **32**.

## Build

```bash
./gradlew assembleDevelopment
```

APKs: `app/build/outputs/apk/development/app-{arm64-v8a,x86_64}-development.apk`
