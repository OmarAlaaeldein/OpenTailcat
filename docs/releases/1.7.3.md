# OpenTailcat 1.7.3

## Changes

- **Share this phone can use a relay you run.** The share screen takes a host
  name and DERP/STUN ports. The default is still the nearest public DERP
  region. A named relay is embedded in the session code, so the guest needs
  no matching setting, and the node does not fetch the public DERP map. An IP
  address or loopback name is refused. The choice lasts for that share only.
- **Controls use light text.** Content colors are light text tokens. Check
  marks are light on the deeper teal fill. The page background is no longer
  used as a font.

## Verification

Android unit tests for the GitHub flavor, including `ThemeContrastTest`.
Development APKs for both ABIs, signed with the pinned development key, with
the updater pointed at `OmarAlaaeldein/OpenTailcat`.

The relay parsing is covered by `exitnode_bridge_test.go` and
`TunnelExitNodeTest`. Not done this release: a physical phone as the host, a
live share through a self-hosted relay, and battery over a long session.
