# OpenTailcat 1.6.0

Development preview, versionCode **49**, signed with the existing development
key. The data plane remains a test-routing preview and is not accepted for
privacy-sensitive traffic.

## Changes

- Fix connect/disconnect and reconnect races across Android service instances,
  including stale start jobs, delayed STOP intents and queued starts.
- Prevent obsolete pump callbacks and telemetry/network callbacks from changing
  a newer or stopped session.
- Align Kotlin and Go token validation, reject malformed UTF-8, and make error
  classification deterministic.
- Disable app HTTP connection reuse across tunnel transitions so an earlier
  protected connection cannot remain pooled into a later VPN session.
- Add lifecycle model checks, focused cleanup and termination checks,
  reproducible counterexample schedules, fuzz targets and shared parser
  differential fixtures.
- Add Android platform regression coverage for queued/newer-start service
  ordering and harden the formal checker against incomplete runs and crashes.

## Verification

Release validation and artifact hashes will be recorded here after the 1.6.0
emulator tests and complete CI finish.

Physical leak capture, roaming/IPv6 WAN acceptance, and production signing
remain outstanding. Reconnect attempts have no TUN between them; Android
Always-on lockdown is required to block traffic during those gaps.
