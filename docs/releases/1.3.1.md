# OpenTailcat 1.3.1

Small usability release on the 1.3 line. Development signing when
`OPENTAILCAT_RELEASE_*` is unset.

## Highlights

- Screenshots: activity-wide `FLAG_SECURE` removed. Token paste dialog still
  sets it only while open so the Connected home / settings screens can be
  captured.
- Always-on VPN + Block connections without VPN is **recommended**, not
  required. Connect and default routes work without those settings; Settings
  copy and README say so. `LockdownProbe` remains for optional status display.
- Split-tunnel exclusions are still refused.
- Version **1.3.1** / versionCode **31**.

## Build

```bash
./gradlew assembleDevelopment
```

APKs: `app/build/outputs/apk/development/app-{arm64-v8a,x86_64}-development.apk`
