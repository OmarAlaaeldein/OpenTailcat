# OpenTailcat 1.2.11

Development build. Not a production privacy VPN. `ipv6` remains false.

## What changed since 1.2.10

- Fix CONNECTED blackhole / tunnel death from typed-nil `net.Conn.Close()` in the
  TCP proxy and DNS-over-TCP paths. `c != nil` is true for typed-nil interfaces;
  Close panicked as `tcp proxy panic: invalid memory address`, and `recoverFlow`
  previously marked the whole session FAILED.
- `closeConn` uses `isNilConn` before Close at every dial failure site.
- Per-flow panics (tcp/udp proxy, dial, copy) are contained without
  `reportPumpDead`; only required pumps (`gvisor output`, `udp gc`) still
  fail-closed.
- `panicSite` skips `runtime.*` frames so logs name the faulting function.
