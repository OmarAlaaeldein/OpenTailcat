# OpenTailcat 1.3.7

Fixes Phase 8 pcap analysis of Linux SLL2 frames and records the 2026-09-23
gateway dual-capture run. No data-plane capability promotions.

## Fixes

- **Phase 8 analyzer SLL2 parse**: payload offset is the fixed 20-byte
  Linux SLL2 header. The previous `12 + addr_len` path missed frames with
  `addr_len = 0` (common on `tcpdump -i any`), so real gateway captures
  could show zero probe destinations even when TCP/443 to `1.1.1.1` was
  present. Unit test covers `addr_len` 0 and 8.
- Rebuilt AAR from that source (`build-aar.sh`); sourcehash and sha256
  sidecars updated and CI-gated.

## Documentation

- `handoff.md`: Phase 8 dual-capture run log for 2026-09-23 (gateway netns
  + Colima outer), analyzer PASS/FAIL examples, and scope: phone-side
  uplink capture is still required for acceptance.
- `scripts/phase8/capture-mac-host.sh`: optional Mac `en0` capture helper.

## No data-plane capability promotions

- IPv4 test-routing flags unchanged; Phase 8 physical leak acceptance still
  pending (`testRouting: true`). This release is **not** a leak-free or
