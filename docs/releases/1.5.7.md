# OpenTailcat 1.5.7

Development preview, versionCode **46**, signed with the existing development key. The data plane remains a test-routing
preview and is not accepted for privacy-sensitive traffic.

## Changes

- Display a valid pasted gateway token as a QR code for sharing. The code contains
  the token and should be shared only with someone trusted.
- Scan a QR code with an installed compatible external scanner, without granting
  OpenTailcat camera permission. The scanner receives the token. Paste remains
  available when no compatible scanner is installed.
- Add ZXing core for QR encoding and update third-party notices.

## Verification

- Both GitHub and F-Droid debug unit tests and lint passed, including a QR
  encode/decode round-trip. Merged manifests contain no camera permission.
- QR scanning via an external app has not been verified on a device.
- Production signing, upgrade lineage, physical leak capture, roaming, and IPv6
  WAN acceptance remain open. Reconnect attempts have no TUN between them;
  Android Always-on lockdown is required to block traffic during those gaps.
- GitHub development APKs build successfully with release optimization. Both
  ABI splits report versionCode 46 and the existing development certificate
  `dd767011a3d1223c6145cec024dccb02730e73607fc39544b2fac93adeafa8d6`.
