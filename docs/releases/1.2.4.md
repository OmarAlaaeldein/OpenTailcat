# OpenTailcat 1.2.4

Development build. Not a production privacy VPN. `ipv6` remains false.

## What changed

- **H1**: Lockdown (`isLockdownEnabled`) is checked only after a host-only warm TUN exists, then before default routes. Connect no longer deadlocks against Always-on lockdown reporting.
- **H2**: After Tailcat `netns.SetEnabled(false)`, Android re-enables netns so `VpnService.protect` applies to Magicsock/DERP sockets. Call `EnsureTransportProtect` after prepare as well.
- **H3**: Attach publishes bridge ownership before pump start; Start fails if a reader dies during readiness (`/dev/null` regression).
- **H4**: DNS-over-TCP fallback tracks connections, sets I/O deadlines, and bounds `Close` wait.
- **H5**: Health freshness requires successful `DiscoPing`; one-shot Meow `Ping` no longer clears failures or refreshes health.
- **H6**: VPN interface FD adopt/clear/shutdown serialized; newly established descriptors cleaned up if startup is cancelled.
- **H7**: phase8-analyze requires a gateway capture; rejects empty/unsupported/undecodable pcaps; decodes Linux SLL2 without treating unknown DLTs as raw IP.
- DnsValidator accepts IPv6 addresses whose last hextet is `53` / `5353`; rejects signed IPv4 like `+1.1.1.1`.
- Docs/version drift: SECURITY and packaging aligned to 1.2.4 / versionCode 17.
