# OpenTailcat 1.5.9

Development preview, versionCode **48**, signed with the existing development key. The data plane remains a test-routing preview and is not accepted for privacy-sensitive traffic.

## Changes

- Update Tailcat and its transport dependencies, including an upstream netstack shutdown fix.
- Update the Go and Gradle toolchains and Android libraries, and rebuild the native engine.

## Verification

- Both flavors' debug unit tests and lint, native Go tests, race tests, vet and staticcheck, and the Phase 8 synthetic analyzer passed.
- F-Droid release APK and GitHub release bundle builds passed. Govulncheck found no reachable vulnerabilities; three vulnerabilities in required modules were reported as uncalled.
- Both APKs report versionCode 48 and the existing development certificate `dd767011a3d1223c6145cec024dccb02730e73607fc39544b2fac93adeafa8d6`.
- Physical leak capture, roaming, IPv6 WAN acceptance, and production signing remain outstanding. Reconnect attempts have no TUN between them; Android Always-on lockdown is required to block traffic during those gaps.
