# OpenTailcat 1.5.5

Development maintenance build, versionCode **44**. Physical-device Phase 8
acceptance and production signing remain pending. No capability is promoted
by this release; `testRouting` remains true.

## Changes

- The Tailcat submodule moves from the signed `v0.7.0` tag to upstream `main`
  at `52fbad32` (2026-10-07, `v0.7.0-17-g52fbad323`). Upstream has published no
  newer release, so this pin is untagged and unsigned; it is recorded that way
  in `third_party/PROVENANCE.md` and must be re-pinned to the next signed tag.
- Telemetry reports the DERP region the running client actually relays through,
  using `Client.DERPRegion()`. The region ID, code, and name are sampled with
  the existing 5 s RTT probe, so a mid-session relay switch is visible instead
  of the region the token advertised at pairing time. The token's embedded map
  remains the fallback until the first sample, and nothing is invented when
  neither source has a region.
- Dependency graph follows the pin: `tailscale.com`
  `v1.103.0-pre.0.20260929142145-a0e471a35b8f`, `wireguard-go`
  `v0.0.0-20260924224943-0a83b87f7908`, `klauspost/compress` 1.20.0, and
  `fxamacker/cbor` 2.9.6.
- Not adopted from the same range: upstream's breaking server API change
  (`AllowedClients` became the `AllowClient` hook, plus `StartContext`,
  `PeerKey`, and `DisconnectClient`) does not affect an initiating client, and
  `Client.Status()` still does not exist, so WireGuard peer counters stay 0.
- Dependabot is disabled. A Go module or submodule bump changes the compiled
  native library, which the bot cannot rebuild, so dependency updates are
  applied by hand with an AAR rebuild and the usual gates.
- Build tooling on `main`: Gradle wrapper 9.8.2, Kotlin 2.4.21,
  `androidx.core:core-ktx` 1.19.1, `actions/setup-java` 6.1.0, and
  `gradle/actions/wrapper-validation` 6.4.0.
- The UDP datagram test helper serialized `Write` against `Close`. The old
  helper could send on a channel another goroutine closed, which the race
  detector caught roughly once per hundred runs and which failed one CI run.

## Remaining gates

Physical uplink and gateway capture, Wi-Fi/cellular handover acceptance,
gateway IPv6 WAN evidence, release-key backup, signing migration, and production
release checks remain open. Reconnect attempts have no TUN between them, so
Android Always-on lockdown is required to block traffic during those gaps.

The live DERP region is measured, but it does not make the relay path itself a
tested data-plane route: direct-versus-DERP transitions still need the Phase 7
evidence before `liveStats` can be promoted.

## Build

```bash
env GOTOOLCHAIN=go1.27.3 core-engine/build-aar.sh
OPENTAILCAT_REPO_SLUG=<owner>/<repo> ./gradlew assembleGithubDevelopment
./gradlew assembleFdroidRelease -PnoAbiSplits
```

GitHub development APKs are split by ABI under
`app/build/outputs/apk/github/development/`. F-Droid release output is unsigned
unless an explicit production signing configuration is supplied.
