# OpenTailcat 1.5.4

Development maintenance build, versionCode **43**. Physical-device Phase 8
acceptance and production signing remain pending. No capability is promoted
by this release; `testRouting` remains true.

## Changes

- The native engine is built with Go 1.27.3, which fixes GO-2026-6809:
  `crypto/x509` now distrusts the compromised intermediate certificates that
  Go 1.27.2 still accepted.
- Android underlay selection follows the platform's default network and
  API 31+ best matching non-VPN callback. API 26–30 uses the platform-reported
  transport or a sole visible candidate; ambiguous underlays stay unknown. Resolver ordering follows the selected underlay.
- Kotlin token validation checks structured DERP field types and integer
  bounds before converting values, and rejects unsafe mapped IPv6 endpoints.
  The shared Kotlin/Go corpus now has 90 generated fixtures, preserving the
  original 46 and covering mapped unspecified addresses in both parsers.
- CI rebuilds the AAR with pinned Go/NDK inputs, checks the Go module list,
  exported Java API, and source hash against the committed artifact, and
  archives API, dependency, hash, and ELF alignment reports. `gobind` is built
  from the module's pinned version.
- The updater pins a future release certificate alongside the existing
  development certificate. This prepares migration; APK signing has not
  rotated. See [signing.md](../signing.md) for backup and compatibility gates.
- `AGENTS.md` is the single engineering contract and phase plan; `handoff.md`
  redirects there. Prose, workspace paths, and the project's own author
  attributions use neutral project references. The updater's repository slug is
  no longer tracked source: it is injected at build time from
  `OPENTAILCAT_REPO_SLUG` (or `-PopentailcatRepoSlug`), and the tracked default
  is a neutral placeholder. A published build must supply the real slug or the
  in-app update check cannot find this repository.

## Remaining gates

Physical uplink and gateway capture, Wi-Fi/cellular handover acceptance,
gateway IPv6 WAN evidence, release-key backup, signing migration, and production
release checks remain open. Reconnect attempts have no TUN between them, so
Android Always-on lockdown is required to block traffic during those gaps.

The Kotlin parser and capability contract stay in place: native validation
remains mandatory, the shared corpus already existed, and build capabilities
are distinct from per-session health and egress probes.

## Build

```bash
env GOTOOLCHAIN=go1.27.3 core-engine/build-aar.sh
OPENTAILCAT_REPO_SLUG=<owner>/<repo> ./gradlew assembleGithubDevelopment
./gradlew assembleFdroidRelease -PnoAbiSplits
```

GitHub development APKs are split by ABI under
`app/build/outputs/apk/github/development/`. F-Droid release output is unsigned
unless an explicit production signing configuration is supplied.
