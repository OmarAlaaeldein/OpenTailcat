# OpenTailcat 1.5.2

Packaging release for F-Droid. No app-behavior changes for the GitHub build.
Development build: signed with the same development certificate as 1.5.1, so
it installs over it and the in-app updater accepts it. Phase 8 physical leak
acceptance is still pending (`testRouting: true`). This is **not** a
production, secure or leak-free VPN release.

## Changes

- **`fdroid` product flavor** (`app/build.gradle.kts`): builds with
  `BuildConfig.UPDATER_ENABLED = false`, compiling out the GitHub Releases
  self-updater so F-Droid builds never fetch or install APKs. The default
  `github` flavor keeps the updater.
- **Universal APK option**: `-PnoAbiSplits` disables ABI splits and builds one
  APK with arm64-v8a and x86_64 (F-Droid needs a distinct versionCode per APK).
- **Store metadata**: `fastlane/metadata/android/en-US/` descriptions,
  screenshots and changelogs.

## Verification

- `./gradlew assembleFdroidRelease -PnoAbiSplits`
- `./gradlew testFdroidDebugUnitTest`

## Build

```bash
./gradlew assembleGithubDevelopment
./gradlew bundleGithubDevelopment
./gradlew assembleFdroidRelease -PnoAbiSplits   # F-Droid (unsigned)
```

APKs: `app/build/outputs/apk/github/development/app-github-{arm64-v8a,x86_64}-development.apk`

Version **1.5.2** / versionCode **41**.
